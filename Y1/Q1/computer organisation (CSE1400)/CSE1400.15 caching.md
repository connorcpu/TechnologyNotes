where does one put the data in cache    
- 'mapping'
   - direct/static: figure out some key as part of the key, put it in that spot, now you can tell straight away if it's in the cache or not; top 5 bits are tag, 7 bit for what page, 4 bits for index into page
   - (fully) associative cache/dynamic, you need the full tag because how to know where the page is that you are looking for since any page can go literally anywhere
   - mixed/x-way set associative: you mix the 2, every page has a predetermined set it goes into like direct mapping but multiple blocks can fit in the same set like associative cache.
      - x-way set associative means x blocks per set. so 8-way (which is most common) means 8 blocks in each set
