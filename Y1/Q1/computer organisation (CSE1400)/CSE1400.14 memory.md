# DMA 
- designed to help with large transfers since every word word would throw an interupt
- connected to PCI
- gets fed
   - starting address
   - number of words to copy 
   - direction of the transfer 
- status/ctrl register
   - irq bit raises when done only if IE bit is set
   - IE bit, enable interupt, states if DMA should raise IRQ when done
   - r/w bit, 1 is read (read from mem) is mem to IO, 0 is write (write mem) mem to IO
   - done bit, set when done, poll this bit if you wanna poll over interupt (why :shrug:)
- start address: where in MEM to put it 
- word count: how many words to copy 
- IMPORTANT, CPU should write to I/O device ctrl registers before starting DMA

# memory organisation
- 16x8 means 16 words of 8 bits, so 16 bytes
   - byte addressable so 4 addres bits 
   - output is 8 bits so 8 output bits 
   - 1x r/w bit
   - 1x CS bit 
   - 1x pwr 
   - 1x gnd
   - total: 14+2=16
- 128x1 means 128 words of 1 bit 
   - bit addressable so 7 bits address 
   - output is 1 bit so 1 output bits 
   - 1x r/w bit 
   - 1x CS bit 
   - 1x pwr 
   - 1x gnd
   - total: 7+1+1+1+1+1=12
- control inputs:
   - r/w: specifies operations 
   - CS: chip select, which selects what chip is used in a multi-chip memory system (?)
- rows mean what word you are selecting, example: 32x32, you need 5 bits addres, you get 32 bits output 
- colomn bits allow you to select 1 bit out of that 32-bit word, so with a 10-bit address to select 1 bit
