

distributions | notation | pdf/pmf                       | cdf                    | expected value | variance
--------------|----------|-------------------------------|------------------------|----------------|-------
bernoulli     | Ber(p)   | p(0) = 1 -p, p(1) = p         |                        |                |
binomial      | Bin(n,p) | p(k) = $\binom n k p^k (1-p)^{n-k}$ |                        | np             | np(1-p)
geometric     | Geo(p)   | $p(k) = (1-p)^{k-1} p$             | F(k) = 1- (1-p)^k      | $\frac 1 p$      | ${1-p \over p^2}$
uniform       | U(a,b)   | $f(x) = {1\over b-a}$           | F(x) = ${x-a \over b-a}$ | {a+b \over 2}  | $\frac 1 {12} (\beta - \alpha)^2$
normal        | N($\mu, \sigma^2$) | $f(x) = {1 \over \sigma \sqrt{2 \pi}} e^{-\frac 1 2 ({x-\mu\over \sigma })^2}$ |  | $\mu$ | $\sigma^2$
exponential   | Exp($\lambda)   | f(x) = \lambda e^{-\lambda x}$          | $F(x) = 1-e^{-\lambda x}$         |  | $1 \over \lambda^2$
pareto        | Par(\alpha, x_0) | f(x) = ${\alpha x_0^\alpha \over x^{\alpha + 1}}$ | $F(x) = 1 - ({x_0 \over x})^\alpha$ |   | 
poisson       | Pois($\mu$)  | p(k) = ${u^k \over k!}e^{-\mu}$     |                        |  |
