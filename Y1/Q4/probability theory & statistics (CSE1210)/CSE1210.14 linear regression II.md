- categorical variables
   - boolean variable might have influence on the value we are trying to estimate
   - we just add it to the linear regession with a coefficient like $\beta_3$
      - $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + U_i$
      - waar elke $x_n$ een lijst met data punten is
   - if the boolean can have 3 options we should add 2 dummy variables both having the variable 0 & 1
- model assessment: coefficient of determintation
   - meer variable in slecht wegens overfitten
   - maar geen variable lijd tot een horizontale rechte op de hoogte van het gemiddelde van alle $y_i$'tjes
   - explained deviation is hoever voorspelling van de mean aflicht.
   - residual deviation is hoeveel hij daarna naast de voorspelling licht, ook als het echte punt tussen voorspelling en gemiddelde licht.
   - TSS = ESS + RSS
   - $R^2 = 1 - {RSS \over TSS} = {ESS \over TSS}$
   - $R^2$ geeft ongeveer aan hoe goed je model is maar houd geen rekening met overfitting door de hoeveelheid variables
   - aldus $R^2_{adj}$, exacte formule onbelangerijk. in principe een penelty voor het gebruik van extra variables.
