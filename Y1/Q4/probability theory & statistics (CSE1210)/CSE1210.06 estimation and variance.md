## estimation
- if you have a dataset you might wanna estimate the parameters to a distribution based on the data
- to do this, compute the expectation as a function of the parameter(s).
- example: in the case of pareto, $\hat\alpha = {\bar x_n \over \bar x_n - 1}$
- this ofcourse does not quite work for multi-parameter, to solve this: method of moments
## method of moments
- for one parameter, the estimator $\hat \theta$ is calulated as the average times h: $\hat \theta = h(\frac 1 n \sum_{i=1}^n X_i)$
- for 2, the function h takes 2 parameters, that being the same one as above, and the same one but square
- function h is here the function that finds the estimator parameters based on the dataset
- so essentially, find the average of the dataset, then find a formula for the parameter based on the average, then plug in the found average
- for multi-parameter, also find the average of the squares of you data points
- then express both moments as functions of the parameters, then solve for parameters expressed as moments
## bias of an estimator
- estimators might not be correct
- the expected value of an estimator is ofcourse the true parameter: $\mathbb E[\hat p] = p$
- the bias is the difference between the estimator and the true parameter
## variance
- var(x) = $\mathbb E [(x - \mathbb E[x])^2]
- var(x) = $\mathbb E[X^2] - (\mathbb E[X])^2$
## standard deviation
$\sqrt{var(X)}$
