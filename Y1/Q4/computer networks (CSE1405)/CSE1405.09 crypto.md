# crash course in cryptopraphy
- crypto goes on some layer
- CIA triad
   - confidentiality: only authorized parities
   - integrity: no altering
   - availability: resiliant against things like DDoS
- attacker models
   - internal / external
   - local    / global
   - passive  / active
   - static   / adaptive
   - polynomially bounded / computationally unbounded
- definitions
   - cryptosystem the set of algorithms
   - cryptographic keys determine specifics
   - cryptoanalysis, research on breaking crypto
   - kerckhoff's principle: the security of a cryptosystem should not depend on the secrecy of the algorithms.
- encryption
   - symmetric
      - block cypher
         - should have more secure options
         - electronic codebook
            - easy
            - but same inputs means same output
         - cipherblock chaining
            - to solve same inputs meaning same output, we XOR C1 with M2
            - difficult to parallelize
         - counter mode
            - instead of feeding output back in, we add a counter to the initial message, this can be in parallel
      - stream
         - act on each byte individually so you can keep going
         - one-time-pad
         - key must be of a length longer than the text, then just xor the message with the key, to both encrypt and decrypt
   - B-enc is done with s-boxes and p-boxes
      - p-box, easy permutation box, 4 1's go in, 4 1's come out
      - s-box substitues, convert bits to int, go through random ceasar-like table, map back to bits.
      - chain like 30 p-boxes and s-boxes
   - a-symetric
      - pick extremely large prime numbers p & q, like 256 bits large
      - $n = p \cdot q \land \phi(n) = (p-1)(q-1)$
      - then find d & e such that $d \cdot e mod \phi(n) = 1$ (this is hard)
      - public key is (e,n), private key is (d,p,q)
   - hybrid-encription
      - use the asmmetric-key so we can exchange the symmetric key
- Message Authentication Codes
   - append tag to message, with integrity bytes
- digital signatures
   - provides authentication, non-repudiation and integrity
   - sender signs with private key, reader checks public key
- cryptographic hash functions
   - random length input to fixed-length output
   - should not have _ANY_ collision
