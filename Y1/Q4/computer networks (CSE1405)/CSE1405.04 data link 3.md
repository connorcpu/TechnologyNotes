   - channel allocation protocol
      - static: used for sharing equally, almost never used, only in important applications like inside a car
      - dynamic
      - without carrier-sense multiple access 
         - ALOHA: transmit when there is data, if collision: retry after random delay
         - stotted ALOHA: divide time into slot, only transmit at beginning of a slot; 
            - issue is time sync, solution is to wait for base station to signal start of slot
            - way higher impact than you'd think; roughly 2x
            - still used on country scale for 2G mobile network, 3G does slotted ALOHA, 2G still alive
            - trains and smart meters use 2G so you can't turn it off
      - with carrier-sense multiple access
         - 1-persistant: wait of idle then send, so don't talk if other ppl talk
         - nonpersistant: if busy, wait random interval, try again
         - p-persistent: if busy then wait for next slot, if idle, then send with probablitly p so not everyone starts talking at the same time
         - 0.001 persistant goes very high, degrades very slowly
         - non-persistant scales very well
   - collision-free protocol 
      - token ring: connect all computers with 1 wire in a ring; pass in circle; problem is ineffficient and token loss
      - bit-map: static and known stations, common notion of slots, 
         - everyone gets a micro slot during contention pediod if they have data to send.
         - during transmission period just use medium in cannonical order, so if 1, 3 & 7 just have 1 send, then 3 then 7, new contention period
         - only send 1 frame per transmission period
         - issue is mistiming during contention period
         - adding devices is not nice
      - binary countdown: static and known station, distinct priorities
         - everyone sends their priority number if they want to send data
         - then you are allowed to send if at the end the number left is yours
         - every station sends the bit of their priority while listening, if you output a 0 and hear a 1, shut up
         - (start at most significant bit)
         - problem is low priority might never send
         - contion time is ceil(log(n)) instead of N (bit-map) so that's nice
