- symetrische matrix means $A = A^T$
- orthogonale matrix moet
   - orthogonale columnen hebben
   - columnen met lengte 1
   - vierkant zijn
- symetrische reele matrix kan alleen reele eigenwaardes hebben
- als A kan worden geschreven als $A = PDP^{-1}$ das is A diagonaliseerbaar
- als A kan worden geschreven als $A = PDP^T$ dan is A orthogonaal diagonaliseerbaar
- A is orthogonaal diagonaliseerbaar iff and only iff A is symetric
- collectie eigenvectoren worden vaag spectrum van vector genoemt
1. find eigenwaardes of A
2. construct basis for every eigenspace
3. construct orthonormal basis for every eigenspace, either using gram-Schmidt or by normalizing your vectors
4. construct matrix P using orthonormal basis vectors you found
