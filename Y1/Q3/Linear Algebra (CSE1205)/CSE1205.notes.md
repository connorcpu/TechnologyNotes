# endterm stuff
- algebraic multiplicity is how many times one solution occurs in the characteristic polynomial ($\lambda = 2 \lor \lambda = -4 \lor \lambda = 2) gives algebraic multiplicity 1 for -4 and 2 for 2
- geometric multiplicity is the dimesion of the eigenspace, it's the amount of free variables when solving $(A-\lambda I)x = 0$
- $1 \leq geometric multiplicity \leq algebraic multiplicity$
- if geometric multiplicity and algebraic multiplicity are the same for every eigenvalue the matrix is diagonalisable
- alternatively, if the geometric multiplicities add up to n for an n x n matrix the matrix is diagonalisable
- to find the basis eigenspace of a diagonalisable matrix $A = PDP^{-1}$ find the basis of the eigenspace of D (eigenvalues are the same for D and A) then multiply each vector by P
- rank of a column is the dimention of the column space, aka the amount of piviots you have in the echelon form
- to do the power of a matrix, diagonalize it and then do the power of the diagonal matrix BY MULTIPLYING THE DIAGONAL WITH THE POWER **DO NOT POWER THE ENTRIES**
- similar matrices have the same eigenvalues but the eigenvectors are  multiplied with matrix P in A = PDP^{-1}
- to make a diagonal matrix, get the eigenvalues and the eigenvectors, then put the eigenvalues on the diagonal of D and the eigenvectors in P in the same column as it's eigenvalue

- matrix multiplication (WHEN COMPUTING AB YOU APPLY B TO THE VECTOR FIRST THEN A:
   - dotproduct: get the dotproduct between the rows of the left matrix and the columns of the right matirix. the columns and rows give intuative coordinates in the output matrix, if not, you are applying AB in the wrong order
   - column rule: apply matrix A to every column of B as a vector to find the columns (as vectors) of the output matrix

- matrices are invertable if their determinant is NOT 0

## invert
- IF A is an nxn matrix that is invertable then:
   - a. A is row equivalent to $I_n$
   - b. A has n pivot positions
   - c. the equation Ax=0 only has the trivial solution
   - d. the columns of A are linearly independent
   - e. the equation Ax = b has at least one solution for each B in $\R^n$
   - f. the columnsspace of A spans $\R^n$
   - g. there exists a nxn matrix such that $CA = I$
   - h. there exists a nxn matrix such that 4AD = I$
   - i. $A^t$ is also invertable
   - j. the columns for a basis for $\R^n$
   - k. col(A) = $\R^n$
   - m. rank(A) = n
   - n. dim(nul(A)) = 0
   - o. nul(A) = $\{\vect 0\}$
