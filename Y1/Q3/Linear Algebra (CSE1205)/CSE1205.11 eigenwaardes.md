- eigenwaardes
   - $\lambda$ is a eigenwaarden als de vergelijking $A\vec x = \lambda \vec x$ has a non-zero solution.
   - vector solutions for $\vec x$ are eigenvectors
   - if there is 1 non-zero solution then there are infinite solutions
   - eigenruimte is the space of the set of all vector solutions for a given $\lambda$ including the zero vector
   - eigenruimte is de nul ruimte van $(A-\lambda I)$
   - als ${\lambda_1, ..., \lambda_p}$ verschillende eigenwaardes van A zijn, en ${\vec u_1, ..., \vec u_p}$ zijn de bijbehorende eigenvectors, dan is die set van vectoren linear onafhankelijk (zolang niet de 0 vector)
   - an NxN matrix can have at most n eigenwaardes (solutions for lambda)
   - for a lower- or upper-triangular matrix the eigenwaardes are listed on the main diagonal
   - charactaristic equation of a matrix is the polynomial you got when trying to get the determinant of $A-\lambda I$.
- to find an eigenwaarden, get $\det (A-\lambda I) =0$
