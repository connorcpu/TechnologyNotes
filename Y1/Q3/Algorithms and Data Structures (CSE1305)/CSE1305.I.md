- hash-map implementation
   - usually consists of one mathematical function and one compression function
   - math function can output anything so compression function is used to bring it within the range of the hashtable
      - simlpe f(x) = x mod N works well if N is prime (N is size of hashtable)
      - more complex ((Ax+b) mod P) mod N, where p >= N and P is prime. A and b sould be between 0 and P-1
   - collision can still happen and should be resolved:
      - separate chaining: implement a secondary function to resolve the collision, the advice is an unordered list because the number of collisions in any given bucket is small and varies
      - open addressing: whenever a collision occurs, just try one address further, also loop around once you reach N

- what is kruskal's algorithm
   - minimum spanning tree
   - every node is a cluster
   - find the smallest edge that's not inside a cluster
   - join the 2 adjacent clusters with that edge 
   - mark that edge as part of the minimum spanning tree
