## functies

- niet injectiefe functies hebben soms geen inverse, want hoe moet je het omdraaien als 1 output 2 inputs had?
- function is a $\forall \alpha \in A \exist !b \in B: (a, b) \in R$ (for every input exactly 1 output)
   - $\exists !b$ means exactly 1 
- $R \subseteq a \times B$
- function name: $f: a \to b$
   - f is function name 
   - a is input (domein)(type output geen set)
   - b is output (codomein)(geen set)
   - bereik/range is set van alle outputs, die berijkt worden
   - set van alle inputs, is gwn het domein want elke input moet mappen naar *een* output
- functie is set van tuples (koppels)
- per definitie van een functie hebben verticale lijnen 1 snijpunt (verticale lijn test)
- within CSE1200, functions are implicitly $\subseteq \R \times \R$
- no given domain means maximum subset of $\R$
- inverse notatie is $f ^{-1}(x) = g(x)$
   - definitie: $(f \circ f^{-1})(x) = x$
- functie is inverteerbaar als hij one-to-one is (injectief) (outputs hebben maar 1 input)
- functie $f^{-1^{-1}}$ does not mean $f^{-1^{-1}} = f$
   - $f(x) = \sqrt x$ (met domein $[0, \infin$ en co-demein $\R$) (belangerijk want volgende stap)
   - $f^{-1}(x) = x^2$ (because domain and codomain swap)
   - $f^{-2} = \emptyset$ because the inverse of $x^2$ is not a function as it fails the vercical line test)

### compositie
$f: A \to B$  
$g: B \to C$  
$h: A \to C = g(f(x))$   
$h = (f \circ g)(x)$   
$f \circ g$ almost never equals $g \circ f$

## inverse functies
- maakt functies 'ongedaan' meestal niet maar soms wel

- als g inverse is van f: $f(x) = y \to x = g(y)$

## inverse trigo functies
sinus spiegelen werkt natuurlijk niet, output is geen functie, dus geen inverse van sinus, valt alleen te does als je sinus domein beperkt.
Als je dus domain beperkt, dan word dan een beperkt codomein voor de inverse. inverse van sinus met beperking heet sinusboog is
$sin^{-1} = arcsin$   
- arcsin:
   - $-1 \leq x \leq 1$
   - $-\frac{\pi}{2} \leq y \leq \frac{\pi}{2}$
- arccos:
   - $-1 \leq x \leq 1$
   - $0 \leq y \leq \pi$
- arctan:
   - $-\infin \leq x \leq \infin$
   - $-\frac{\pi}{2} \leq y \leq \frac{\pi}{2}$

## limieten
- waneer linker en rechter limiet zelfde zijn dan is er geen limiet 
- functie is contiue als $\displaystyle \lim_{x \to a}f(x) = f(a)$
