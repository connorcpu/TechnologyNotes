## absolute / relatieve convergentie
### absolute convergence
1. take absolute value of the function
2. simplify if possible
3. make it converge 
4. call it "absolutely convergent"
5. infer it's also regular convergent   
proof: 
- $\displaystyle 0 \leq \sum_{n=1}^\infty (a_n + |a_n|) \leq \sum_{n=1}^\infty 2|a_n| = 2\sum_{n=1}^\infty |a_n|$

### relatief / conditioneel convergent
- convergent maar niet absoluut convergent? -> relatief convergent
- example: $\displaystyle\sum_{n=1}^\infty \frac {-1^n} n$ (standaart voorbeeld wat je moet kennen)

## ratio test 
- als je een reeks hebt, en geen van die termen is 0, suppose $\lim_{n\to\infty} {|a_{n+1}| \over a_n} = L$ als:
- $L < 1$ dan is de reeks convergent 
- $L = 1$ of onbestaande limiet is inconclusief
- $L > 1 \lor L = \infty$ divergent
