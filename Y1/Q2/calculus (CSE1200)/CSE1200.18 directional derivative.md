- given:
   - a function of several variables
   - a point on the function 
   - a unit vector along the function
- it is possible to derive the function along the unit vectors direction
- to do this, simply add up the partial derivatives multiplied by the unit vectors length in that direction:
   - $D_{\vec u} f(x,y) = f_x (x,y) u_1 + f_y (x,y) u_2$
   - where the unit vector is given by $\vec u = <u_1, u_2>$
- to acquire a unit vector from any vector we have to normalize it:
   - $\hat{u} = {1 \over |\vec u|} \vec u$
