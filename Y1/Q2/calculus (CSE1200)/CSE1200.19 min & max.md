## extreme waarde
definitie maxima: c where $\forall a \in A f(a) \geq f(c)$  
- $f\cdot [-1, 2] \to \R$ is een gesloten interval en dus heeft het een maximum
- $f\cdot (-1, 2) \to \R$ heeft wel een maximum want het is een open interval

## regia
- een regio is 'bounded'/'begrenst' als ik een cirkel kan opstell om de oorsprong waar elke waarde binnen de cirkel valt
- anderzijds, in n dimentionele ruimte, moet ik een positief getal kunnen kiezen ($m > 0$) waar als ik een vector x opstell zodat $|\vec x| < m$

- een regio is 'closed'/'gesloten' als alle grenspunten in de regio liggen (?)
- D = {(x,y) $\mid x < 1 \mid |x| \leq$ z}
- grenspunten kan ik willekeurig goed benaderen met punten in de regio, en willegkeurig goed met punten niet in de regio
- voorbeeld: $D = \{ (x,y)\in \R^2 | -1 < x \leq 1 | -1 < y \leq 1\}$ is gesloten
- regio kan ongesloten en onopen zijn (?)

## critical points
- alle particiele afgeleide moeten 0 zijn, das een maxima
- kritieke punt is een punt waar elke particiele afgeleide op dat punt gelijk is aan 0 of niet bestaat

## how to find min or max 
- we need 
  1. gesloten

  3. continue

## second derivative test
example:   
   - $f(x)=x^2$
   - critical point: x=0
   - second derivative: $f''(x) = 2$
   - first derivative: $f'(x) = 2x$
   - that means below the critical point we have negative first and positive second so afnemend dalend
   - that means above the critical point we have positive first and positive second so toenemend steigend
   - therefore, minimum

q: how many critical points?
formula: $f(x,y) = 12xy - x^3 - y^3$
- answer: 2
- how: we need 2 partial differentials
   1. we find $12y - 3x^2$
   2. 2. and $12x - 3y^2$
   3. both need to be equal to 0
   4. algebra says $x=\frac 1 4 y^2$
   5. $y = \frac 1 4 x^2$
   6. so: $y = \frac 1 4 (\frac 1 4)x^2)^2$
   7. so $y = 0 \lor y=4$
