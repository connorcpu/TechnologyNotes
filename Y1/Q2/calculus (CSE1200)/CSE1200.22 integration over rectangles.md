# integratie op 2 variabele
## 1 var
-  $\displaystyle\sum_{i=1}^n f(x_i)$ 
- $\displaystyle\lim_{n\to \infty}\sum_{i=1}^n f(x_i)\Delta x = \int_a^b f(x) dx$
## 2 var
- $\displaystyle\sum_{i=1}^n \sum_{j=1}^m f(x_{i,j},y_{i,j}) \Delta x \Delta y$
- $\displaystyle\lim_{n\to \infty}\lim_{m\to \infty}\sum_{i=1}^n \sum_{j=1}^m f(x_{i,j},y_{i,j})\Delta A_i = \iint_a^b f(x) dA$

# iterated integrals
- $\displaystyle\lim_{n\to \infty}\sum_{i=1}^n (\int_a^b f(x, y_n) dx)\Delta y$
