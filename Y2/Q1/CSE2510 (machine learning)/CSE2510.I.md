      - classification
         - discriminative
            - linear
               - logistic regression: use a sigmoid to map everything to a value between 0 and 1. put all samples through a 1xn matrix, offset by some bias. put that into the sigmoid function. outputs a confidance for a given class. requires gradient decent
               - SVC: maximize the margin between (correctly classified) data points, hard if everything needs to be classified correct. soft if it only counts correctly classified ones
            - non-linear
               - decision trees
               - MLP (multi-layer perceptron): getting something wrong means backpropegating using the chain run backwards through the network to find a gradient. then decend the gradient
         - generative
            - linear
               - LDA (linear discriminant analysis): share the covariance matrix
               - nearest mean
            - non-linear
               - k-NN
               - QDA (quadratic discriminant analysis): 1 covariance matrix per class
               - naive bayes
               - Parzen
   - unsupervised
      - clustering
         - K-means: i want k clusters, i devide the centroids over the space, then classify each sample by the nearest centroid, then i move the centroid to the averag of the samples, then reclassify, and move again
         - hierachrical
            - agglomerative (bottom-up): each point is a cluster, group the 2 clostest clusters. stop at some point
               - how do you decide what clusters are close? you can use the furthest 2 points from each other (complete linkage). or the average of the cluster (cluster centres), or the clostest (single linkage)
            - divisive (top-down): all points start in a single cluster, then divide it in some sensible way. stop at some point
               - you could for example, split the cluster by applying k-means with k=2. and then run that recurvisle down
      - dimensionality reduction
         - PCA: project onto a line/plane etc in such a way we have the highest possible variance




- parametric densities
   - gaussian-densitiy based classification
   - naive-bayes: just assume the features are not correlated at all. this way every feature becomes a 1D classification problem which can be estimated by gaussians, histograms or parzens
- non parametric (instead of guessing parameters of distributions you estimate the chance directly
   - parzen / KDE: count up the density functions (kernel functions) you put around each data point, box = historgram, so basically just a smoothed histogram
   - k-nearest-neighbor: find the k-nearest neighbors, then the majority vote goes for what we should classify as
