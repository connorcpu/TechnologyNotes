- $p(x) = {1 \over \sqrt{(2\pi)^M \det (\Sigma)}} \exp(-\frac 1 2 (x-\mu)^T \Sigma^{-1} (x-\mu))$
### excersize
- p = p(apple) = 1 - p(pear)
- setup the log likelyhood
- assume the dataset is independent
- lets say we have n apples in the data and m pears
- $log(p^n * (1-p)^m)$
- then $ll = n log(p) + m log((1-p))$
- then ${\delta ll \over \delta p} = \frac n p - \frac m {1-p} = 0$
- leads to $p = {n \over n+m}$

- now we need to estimate the parameters
- for each class, estimate the mean by taking the average
   - estimate the coovariance matrix with unbiased estimator $\displaystyle\hat\Sigma = {1 \over N_y - 1}\sum_{i=1}^{N_y} (\vec x_i - \hat \mu_y)(\vec x_i - \hat \mu_y)^T$
   - you _NEED_ to check which estimator your lib implements, the biased version uses $\frac 1 {N_y}$, the diff is usually fine because $N_y$ is the amout of data points you have, so n is very high
- $f(x) = \log p(y_1 | \vec x) - \log p(y_2 | \vec x)$ 
- apply bayes rule: $\log p(y_i | \vec x) = \log p(\vec x | y_i) + \log p(y_i) - \log p(\vec x)$
- f(x) = g(y_1) - g(y_2)
- $g_i(x) = - \frac 1 2 (\vec x - \hat \mu_i)^T \hat\Sigma_i^{-1} (\vec x - \hat \mu_i) - \frac 1 2 \log (\det \hat\Sigma_i) + \log p(y_i)$
- $= - \frac 1 2 x^T \hat\Sigma_i^{-1}x + \hat\mu_i \hat\Sigma_i^{-1} x - \frac 1 2 \mu_i^T \hat\Sigma_i^{-1}\mu_i + \dots$
- $f(x) = x^T (\frac 1 2(\hat\Sigma_1^{-1} - \hat\Sigma_2^{-1})) x + (\hat\mu_1^T\hat\Sigma_1^{-1}-\hat\mu_2\hat\Sigma_2^{-1}) x^{-1}$
