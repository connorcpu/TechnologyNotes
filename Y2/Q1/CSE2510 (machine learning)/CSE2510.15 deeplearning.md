# stuff
- general idea is fuck feature extraction, let the AI figure that out too
- just dump whatever info you have into the neural network and have it do it
- the antialiasing problem, you can't fix noise with a moving average
- kernel's can be used to extract features
- popular non-linearity function is ReLu, which takes the max(0, x). sets negative to 0 essenstially
- convolutional network:
   - learned filters(kernel)
   - convolution (output of kernel)
   - non-linearity (such as ReLu)
   - spatial pooling (average every 4 pixels)
   - then output that to the next layer
- transfer learning:
   - teach the network on a big data set and then adapt it to your (too small) dataset
   - leave the convolution layers but change out the fully connected layers
   - only put every image through the convolution once, then just deep learn the fully connected layer
