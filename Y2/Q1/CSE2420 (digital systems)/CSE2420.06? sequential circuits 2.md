   - S switches Q on

- D latches
   - switching the D input on, causes S to be raised
   - switching the D input off, causes R to be raised
   - changes are only carried through if enable is raised. this means to keep state just leave enable low
   - to save a state. switch D to the desired state. then pulse enable
